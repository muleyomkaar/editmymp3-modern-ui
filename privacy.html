Privacy

EditMyMP3 is designed so ordinary MP3 editing, merging and MP3-to-WAV conversion happen in your browser. Your selected audio file is not intentionally uploaded to our server for these operations.

AI edit planner

If you use the AI edit feature, your written instruction and audio duration are sent through our server endpoint to the configured AI provider so it can return edit settings. The MP3 itself is not required for this planning request.
